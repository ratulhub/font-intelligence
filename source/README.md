# Source Font Packages

In this repository, the third-party source packages are preserved in:
`All fonts/` (at repository root)

## Source Package Preservation Principles
As mandated by the Font Intelligence Architecture:
- Original source packages are preserved in their native foundry structures without destructive renaming or file deletion.
- Licenses, readmes, and specimen preview images are kept directly with the font packages.
- The canonical catalog (`catalog/fonts.json`) indexes all source binaries and maps them to normalized font IDs.

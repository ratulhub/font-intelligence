The Core Problem

Why Current AI Typography Fails

When AI agents write front-end code, they default to three fonts, guess weights that don't exist, and break multilingual text.

The Typical AI Default

Predictable & Broken

  • Lazy Defaulting: Suggests Inter, Roboto, or Arial for every project regardless of industry or vibe.
  • Faux Bold Blurs: Emits CSS weights like font-weight: 500 for families that only ship Regular (400) and Bold (700).
  • Language Tofu: Guesses Bengali, Arabic, Cyrillic, or CJK coverage, rendering broken empty boxes to international users.
  • Decorative Fatigue: Uses high-flair display typefaces for continuous 13px body text.
  • Repository Bloat: Leaves heavy multi-megabyte skill folders and hundreds of unneeded font files inside your repo.

Algorithmic Framework

The 10-Dimension Scoring Model

Every pair candidate is evaluated against 10 weighted dimensions summing to 100%. Only high-harmony combinations survive.

1. Visual Contrast 15% Weight

Requires a confirmed weight delta of ≥ 200, or structural serif-to-sans tension. Prevents flat, muddy visual hierarchy.

2. Readability & Endurance 15% Weight

Measures x-height, aperture openness, stroke modulation, and counters. Enforces a strict minimum of 7/10 for body and UI.

3. Serif / Sans Dynamic 12% Weight

Balances optical cadence between lead and companion, avoiding conflicting stroke terminals or awkward axis conflicts.

4. Personality Resonance 12% Weight

Guarantees historical, cultural, and industry alignment. Prohibits dissonant pairings like luxury Didone paired with techno display.

5. Role Compatibility 10% Weight

Audits whether typefaces are assigned strictly to their verified roles (display faces never used for body paragraphs).

6. Weight Availability 10% Weight

Verifies physical family depth, true italic availability, and variable axis ranges from OpenType metadata.

7. Proportional Width 8% Weight

Checks optical balance between headline letter width and body column width, avoiding ultra-condensed with ultra-extended.

8. Project Style Fit 8% Weight

Direct alignment with one of 29 defined use-case archetypes (Fintech, SaaS, Editorial, Mobile, eCommerce, etc.).

9. Language Parity 5% Weight

Audits OpenType cmap tables to ensure headline and body render target scripts without missing character glyphs.

10. Platform Suitability 5% Weight

Enforces web payloads under 100 KB, Flutter engine compatibility, and TrueType outlines for Microsoft PowerPoint embedding.

Quality Safeguards

The 10 Anti-Pattern Shields

If a candidate pairing commits any typographic anti-pattern, severe point penalties are subtracted automatically.

Decorative as Body -45 pts

Strictly prohibits display, handwriting, or decorative typefaces in continuous body or UI roles.

Script Mismatch / Tofu -45 pts

Refuses unverified scripts. If missing, reports 0 catalog fonts and injects verified open-source companions.

Competing Display Fonts -30 pts

Guarantees only one vocal lead font per typographic hierarchy. Two high-personality faces may not compete.

Weak Contrast / Flat -25 pts

Penalizes headline and body with less than 200 weight delta or lacking structural serif/sans classification contrast.

Excessive Font Families -25 pts

Restricts designs to maximum 2 primary families (heading + body/UI), with monospace reserved strictly for code/data.

Personality Polar Clash -25 pts

Prevents emotionally clashing tones, such as high-fashion Didone paired with distressed grunge display.

Low x-Height in UI Microcopy -20 pts

Requires wide apertures and large x-height for 11px to 13px captions, badges, and interface controls.

Hairline Screen Fatigue -20 pts

Prohibits 100 or 200 ultra-thin hairline weights for continuous reading text on digital screens.

Monospace Longform Fatigue -15 pts

Restricts monospace fonts to code listings, timestamps, and tabular data tables. Never continuous prose.

Uncanny Sans Mismatch -15 pts

Forbids pairing two near-identical neo-grotesque sans-serifs that look like an unintentional rendering error.

Repository Hygiene

Zero-Bloat Project Delivery (Step 11)

Skill folders can be heavy. Font Intelligence ensures that once your agent finishes writing your project, only the exact font binaries you used stay in your repository.

1

Diagnostic & Export

The AI agent diagnoses the brief and copies selected font files into your project's fonts/ directory.

2

Project Generation

The agent codes your application, generating CSS custom properties, Tailwind tokens, or Flutter configurations.

3

Automatic Cleanup

The agent runs clean_project.py, scanning CSS/code references and pruning unused weights.

4

Clean Delivery

The temporary skill folder is deleted. Your repository stays feather-light with zero unnecessary files.

Font Intelligence is a typography decision system for AI coding agents, UI/UX designers, and developers. It replaces default choices like Inter, Roboto, and Arial with scored, anti-pattern-checked pairings and copy-pasteable tokens.

Overview

The catalog holds 413 verified families and 1,083 font binaries from 386 source packages. Every recommendation is checked against real weights, real script coverage, and real license terms, then explained in typographic terms.

Features

Quick start

Requires Python 3.10, 3.11, or 3.12. fonttools is optional and only needed for binary inspection.

git clone https://github.com/ratulhub/font-intelligence.git
cd font-intelligence
pip install fonttools          # optional
./install.sh all               # Linux / macOS
.\install.ps1 -Target all      # Windows (PowerShell)

Open the preview studio

The studio needs no dependencies. It filters all 413 families by category, style, role, script, and readability, and includes a live type tester for Latin, numbers, UI controls, and non-Latin scripts.

python -m http.server 8080
# open http://localhost:8080/preview/index.html

Use it with an AI agent

All 8 supported platforms read one canonical skill at .agents/skills/font-intelligence/SKILL.md. Each adapter file only points to it. After installing, ask your agent for UI or typography work and it should apply the skill on its own. To be explicit, use a prompt like this:

Use the Font Intelligence skill. Before choosing any font, read
.agents/skills/font-intelligence/SKILL.md, diagnose the use case,
audit script coverage, and score the pairing. Do not default to
Inter, Roboto, or Arial. Give me the rationale and code tokens.

When the skill activates

  • Designing or coding UI/UX, landing pages, SaaS dashboards, or mobile apps
  • Selecting, pairing, or styling fonts in CSS, Tailwind, Flutter, React Native, or slide decks
  • Branding, editorial design, or typography hierarchy decisions
  • Evaluating legibility, performance budgets, or commercial and redistribution licenses

How it works

Every brief passes through the same eleven steps.

  1. Diagnose the project against catalog/use-cases.json (29 use cases).
  2. Translate vibe words with style_interpretations.
  3. If the user named a font, anchor on it and pair around it.
  4. Filter candidates by the hard rules.
  5. Audit script coverage. Unverified scripts are refused.
  6. Score the pair on 10 dimensions from catalog/scoring.json.
  7. Audit 10 anti-patterns from catalog/anti-patterns.json.
  8. Select only weights listed in technical.weights.
  9. Output the rationale and code tokens.
  10. Export fonts and copy licenses (scripts/copy_fonts.py --prune-unused).
  11. Zero-bloat project delivery: Clean unneeded fonts and remove skill folder (scripts/clean_project.py).

Vibe decoder

Scoring engine

Each pair is scored across ten weighted dimensions. Weights sum to 100%.

Anti-patterns

Each violation subtracts points from a pair's score, from 15 up to 45.

Hard rules

  1. Never invent catalog fonts, weights, or language support.
  2. Never equate commercial use with GitHub redistribution. Verify the license grant first.
  3. Respect explicit user fonts. Adopt them and pair around them.
  4. Do not replace existing typography systems unprompted.
  5. No decorative fonts in body or ui roles.
  6. Maximum 2 primary families: one heading and one body/UI, plus mono when code or data is present.
  7. Readability 7/10 or higher for body and UI.
  8. Respect platform limits: WOFF2 under 100 KB for web, .ttf outlines for Microsoft Office.
  9. Always generate calibrated system fallbacks.
  10. Zero-bloat project delivery: only used font files stay in user project repositories upon completion.

Script support

The zero-tofu policy checks OpenType tables before anything is recommended. Strict character-set thresholds apply to Bengali, Arabic, Cyrillic, Greek, Hangul, Hebrew, and CJK.

When no catalog font supports a script, Font Intelligence reports 0 catalog fonts and names verified open-source companions. These companions are also injected into CSS custom properties and the Flutter and React Native fallback stacks.

Bangla and Arabic map to Hind Siliguri, Noto Sans Bengali, and Amiri.

Code tokens

Output is ready to paste into your project:

  • CSS custom properties
  • Flutter pubspec.yaml entries
  • React Native StyleSheet values
  • Microsoft Office TrueType embedding instructions
python scripts/copy_fonts.py --fonts "chillax,general-sans" --dest "dist/fonts" --snippets all --prune-unused

The export tool bundles licenses and warns loudly when a font is UNKNOWN, RESTRICTED, or PROOF_NEEDED. Existing design-system fonts are never overwritten. Pass them with --existing-fonts.

Reference guides

Catalog

Without Python, read the JSON directly.

The curated baseline is 103 families with 12 hand-written pairings. The other 310 families came from bulk ingestion (scripts/ingest_new_fonts.py), which recorded 1,035 unique SHA-256 hashes and 17 duplicate binary groups without touching source packages.

Licensing

Each font keeps its original license. Free for commercial use does not mean redistributable.

Distribution status

Public release is gated. Only verified permissive families ship in assets/fonts/. The rest stay in the catalog without being redistributed. scripts/validate_public_release.py blocks unauthorized redistribution in CI.

The engine, scripts, decision models, and agent skill files are MIT licensed. Font binaries in All fonts/ keep their foundry licenses.

Validate and contribute

Run these before every push. CI runs the same checks on Python 3.10 to 3.12. There are 81 tests: 58 domain tests and 23 CLI and engine tests.

python scripts/validate_catalog.py
python scripts/validate_licenses.py --filter issues-only
python -m unittest discover -s tests -p "test_*.py"
python -m unittest discover -s scripts -p "test_*.py"
python scripts/run_evaluation_matrix.py

The evaluation matrix runs 16 real project briefs and 8 failure cases (24/24 pass). To add fonts, use cases, or pairings, read CONTRIBUTING.md.

FAQ

Why does a Bangla search return 0 catalog fonts?

No catalog font passes the strict OpenType coverage check for Bengali, so none is recommended. You get verified companions instead: Hind Siliguri and Noto Sans Bengali.

Can I redistribute a font that is free for commercial use?

Not automatically. Commercial permission and GitHub redistribution are separate grants. Check the license in the catalog and docs/redistribution-review.md.

Will it override the fonts I already use?

No. Pass them with --existing-fonts and Font Intelligence works around them. A font you name explicitly is anchored with --anchor.

Why can't it suggest weight 500 for my font?

It only emits weights listed in technical.weights. Requesting a weight a family does not ship causes faux bold or fallback rendering.

Does it work without Python?

Yes. An agent can read catalog/fonts.json, use-cases.json, pairings.json, scoring.json, and anti-patterns.json directly.

How does Zero-Bloat project delivery prevent repo bloat?

Running python scripts/clean_project.py --project-dir <path> parses your project's CSS and code to detect which font files are actually loaded, prunes unreferenced fonts, and cleans the temporary skill folder so only chosen font binaries remain.

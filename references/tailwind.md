# Tailwind CSS Typography Reference

Configuring Tailwind CSS to utilize calibrated typography tokens generated by Font Intelligence.

---

## 1. Tailwind v3 Configuration (`tailwind.config.js`)

Map custom CSS variables to Tailwind font family themes:

```javascript
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ['./src/**/*.{js,ts,jsx,tsx,html}'],
  theme: {
    extend: {
      fontFamily: {
        heading: ['var(--font-heading)', 'system-ui', 'sans-serif'],
        body: ['var(--font-body)', 'system-ui', 'sans-serif'],
        mono: ['var(--font-mono)', 'ui-monospace', 'monospace'],
        bangla: ['var(--font-bangla)', 'Hind Siliguri', 'sans-serif'],
      },
      letterSpacing: {
        tighter: '-0.03em',
        tight: '-0.02em',
        normal: '0',
        wide: '0.025em',
        wider: '0.05em',
        widest: '0.1em',
      },
      lineHeight: {
        display: '1.12',
        heading: '1.25',
        body: '1.625',
        compact: '1.2',
      },
    },
  },
  plugins: [
    require('@tailwindcss/typography'),
  ],
};
```

---

## 2. Tailwind v4 Configuration (`globals.css`)

In Tailwind CSS v4, configure tokens directly using CSS `@theme`:

```css
@import "tailwindcss";

@theme {
  --font-heading: 'Chillax', system-ui, sans-serif;
  --font-body: 'General Sans', system-ui, sans-serif;
  --font-mono: 'Ubuntu Mono', ui-monospace, monospace;

  --tracking-display: -0.025em;
  --tracking-body: 0;

  --leading-display: 1.15;
  --leading-body: 1.6;
}
```
